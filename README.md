# OMNISCIENT — офлайн-first научная обучающая PWA

## Что уже работает
- Русский адаптивный интерфейс для телефона и ПК.
- Каталог дисциплин и переход в учебные темы.
- Начальные учебные конспекты по математике, физике, химии, биологии, астрономии и информатике.
- Короткие проверочные вопросы.
- Локальное сохранение прогресса в браузере.
- Переключение светлой/тёмной темы.
- Service Worker для кэширования приложения и базовой работы офлайн после первого посещения.

## Запуск
Требуется Node.js 20+.

```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
npm run preview
```

## Важно
Это начальная рабочая основа, а не законченная мировая научная энциклопедия. Тексты — вводные конспекты; их необходимо расширять, проверять по авторитетным источникам и снабжать библиографией. Для полной офлайн-доставки нужно размещать локальные шрифты и все учебные данные в приложении. Android APK можно получить через Capacitor/Android Studio или отдельный CI workflow; данный архив пока содержит PWA исходники, не APK.
